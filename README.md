# Spring Boot Hospital Management System (In Progress)

## 🏥 Overview
The **Hospital Management System** is a Spring Boot–based project currently under development.  
It aims to streamline hospital operations by managing patient data, doctor details, and appointments efficiently using a MySQL database.

---

## 🚧 Current Status
This project is **in process**.  
- Database integration with MySQL and Hibernate has been completed.  
- Backend structure (Entity, Repository, Service layers) is being implemented.  
- Controller endpoints and frontend integration are under development.

|----------|---------|
